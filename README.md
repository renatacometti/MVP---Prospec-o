# MVP — Prospecção

Protótipo da tela de condições de financiamento do SISCAP.

## Arquivos

- `index.html`: estrutura da página e da modal de condições de financiamento.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: inclusão, edição, exclusão e pesquisa de condições.

Abra o arquivo `index.html` em um navegador para visualizar o protótipo.
